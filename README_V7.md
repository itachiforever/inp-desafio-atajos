Para WordPress, el iframe debe ocupar toda la ventana y hay que ocultar la cabecera/pie del tema en la página del juego. Ejemplo de iframe: <iframe src="https://inp-desafio-atajos.onrender.com/" style="display:block;width:100%;height:100dvh;border:0" allowfullscreen></iframe>. Si WordPress limita el ancho del contenido, usar plantilla de página a ancho completo y eliminar márgenes. Nota: un iframe no puede ocultar por sí mismo los elementos exteriores de WordPress.
